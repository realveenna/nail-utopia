# Nail Utopia

 Nail Utopia is a PHP-based e-commerce website developed as part of a web development project. The website provides customers with a platform to browse nail products, manage their shopping cart, and place orders, while providing staff and administrators with tools for managing the system.

 ## Project Location

 The main project can be accessed from:

 `nail_utopia/project/main/index.php`

 ## Features

 - Product catalogue
- Product browsing and purchasing
- Shopping cart functionality
- Voucher and discount system
- Newsletter subscription
- User accounts and authentication
- Admin dashboard
- Staff access
- Order management
- Database-driven product and order information
- Responsive interface using Bootstrap

 ## Technologies Used

 - **PHP** – Server-side development
- **MySQL** – Database management
- **HTML/CSS** – Website structure and styling
- **Bootstrap** – Responsive UI framework
- **JavaScript** – Client-side functionality
- **Mailtrap** – Email testing
- **PHPMailer** – Previously used for email functionality

 ## Getting Started

 1. Download or clone the Nail Utopia project.
2. Place the project inside your local PHP server directory, such as `htdocs` when using XAMPP.
3. Configure the MySQL database required by the project.
4. Import the provided database file, if applicable.
5. Check the database connection settings in the project configuration.
6. Start Apache and MySQL through your local server environment.
7. Open the following file in your browser:
    `nail_utopia/project/main/index.php`
8. Use one of the test accounts above to access the appropriate level of the system.
